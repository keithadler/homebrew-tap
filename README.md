# Homebrew tap for Lean Studio

[Lean Studio](https://github.com/keithadler/leanstudio) is a desktop IDE for Lean 4, by Keith Adler
([@keithadler](https://x.com/keithadler)).

```bash
brew install --cask keithadler/tap/lean-studio
```

This installs `Lean Studio.app` for Apple silicon or Intel Macs and puts `leanstudio` on your PATH.
`brew upgrade` keeps it current.

The cask is maintained in the Lean Studio repository at
[`packaging/homebrew/lean-studio.rb`](https://github.com/keithadler/leanstudio/blob/main/packaging/homebrew/lean-studio.rb)
and copied here for each release.
